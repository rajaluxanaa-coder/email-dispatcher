# Automated Email Dispatcher

A Python-based tool that automates sending personalized emails to multiple recipients.

## Features

- Send personalized emails to multiple recipients
- HTML email templates with CSS styling
- Optional file attachments (PDF, images, documents)
- Department-based filtering
- Random delays to avoid spam filters
- Detailed activity logging
- Scheduled email sending

## Tech Stack

- Python 3.7+
- smtplib (built-in)
- csv (built-in)
- email.message (built-in)
- schedule (pip install schedule)
